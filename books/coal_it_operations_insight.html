煤矿运维术语词典（150+术语）

覆盖地质测量、采煤工艺、掘进支护、通风安全、机电运输、IT网络运维、运维管理七大领域。每条含：术语名、英文/缩写、定义、运维含义、IT关联点。

断层Fault
岩层沿断裂面发生明显位移的地质构造
运维含义
断层是采掘工作面最大的地质障碍，遇断层需重新规划巷道布置，可能导致工作面搬家，直接影响产能和设备周转
IT关联点
三维地质建模系统需将断层数据纳入数字孪生底座；GIS平台需实时更新断层揭露信息供采掘决策
褶皱Fold
岩层受挤压形成的弯曲变形构造
运维含义
褶皱影响煤层厚度和走向变化，向斜轴部易积聚瓦斯，背斜轴部顶板破碎，运维需重点关注瓦斯监测和顶板管理
IT关联点
地质测量数据导入矿井GIS后，自动识别褶皱区域并推送预警至智能开采平台
陷落柱Collapse Column
岩溶空洞导致上覆岩层塌陷形成的柱状破碎体
运维含义
陷落柱穿越煤层时造成煤厚骤减甚至缺失，综采面遇陷落柱需绕行或强制推过，严重影响设备安全和生产连续性
IT关联点
物探（三维地震）数据与采掘工程平面图叠加，GIS系统标注陷落柱边界，辅助智能开采路径规划
夹矸Gangue Parting / Dirt Band
煤层中夹杂的岩层（如泥岩、砂岩）
运维含义
夹矸厚度直接影响煤质和采煤机截割效率，厚夹矸需分层开采或留顶底煤，增加设备磨损和生产成本
IT关联点
采煤机记忆截割系统需结合煤岩识别传感器（如伽马射线探测器）实时调整截割高度
煤层结构（简单/复杂）Coal Seam Structure
简单结构煤层无夹矸，复杂结构煤层含多层夹矸
运维含义
简单结构煤层适合大采高一次采全高，复杂结构煤层需分层开采或放顶煤工艺，直接决定工作面设备选型
IT关联点
煤层结构数据是智能化开采系统初始化割煤曲线的关键输入参数
底板比压Floor Bearing Capacity
底板单位面积承受的最大压力（MPa）
运维含义
底板比压不足时液压支架会"压入底板"（扎底），导致移架困难、底座下沉，运维需监测底板条件并选型合适底座面积
IT关联点
支架电液控制系统可集成底板压力传感器，实时监测底板承载状态并预警
含水层Aquifer
含地下水并能透水的岩层
运维含义
含水层是矿井水害的主要威胁源，采掘接近含水层时必须探放水，直接影响工作面布置和防排水系统设计
IT关联点
水文监测系统（水位、水压、水量传感器）数据接入智维中心，实现水害实时预警和联动控制
隔水层Aquiclude
不透水或极弱透水的岩层（如泥岩、黏土层）
运维含义
隔水层是保护煤层免受上部含水层威胁的天然屏障，其厚度和完整性决定防水煤柱留设方案
IT关联点
水文地质数据库管理隔水层厚度分布数据，与采掘工程图层叠加分析
导水裂缝带Water-Conducting Fracture Zone
采空区上覆岩层冒落和裂缝发育形成的含水通道
运维含义
导水裂缝带高度决定"两带"（冒落带、导水裂缝带）范围，是防水煤柱设计和顶板水害防治的核心参数
IT关联点
数值模拟（FLAC3D/UDEC）计算结果纳入地质数据库，辅助智能决策防水方案
防水煤柱Waterproof Coal Pillar
为隔离水源而留设的不采煤层区域
运维含义
防水煤柱尺寸直接影响矿井资源回收率和安全系数，运维需确保煤柱不被破坏，定期监测煤柱完整性
IT关联点
GIS系统标注防水煤柱边界，采掘越界时自动触发报警
探放水Water Exploration and Drainage
使用钻探手段探测前方水体并提前疏放
运维含义
"预测预报、有疑必探、先探后掘、先治后采"是煤矿防治水十六字原则，探放水是采掘前的强制工序
IT关联点
探放水钻孔数据（方位、倾角、深度、出水量）录入地质数据库，形成探放水成果台账
水文地质类型Hydrogeological Classification
按矿井充水条件划分的类型（简单/中等/复杂/极复杂）
运维含义
直接决定矿井防排水标准等级，极复杂类型矿井需配备强排系统和专业防治水队伍
IT关联点
水文监测数据自动采集上传至省级监管平台，数据类型与监测频率由分类等级决定
煤层倾角Seam Dip Angle
煤层与水平面的夹角
运维含义
倾角决定采煤工艺选型：近水平（<8°）适合综采，倾斜（8°-25°）需防倒防滑，急倾斜（>45°）需特殊采法
IT关联点
倾角数据是液压支架选型（防倒千斤顶配置）、采煤机牵引力计算的关键参数，影响自动化开采方案
走向Strike
煤层层面与水平面交线的方向
运维含义
工作面沿走向布置称为走向长壁工作面，走向长度决定工作面推进距离和搬家频率
IT关联点
矿井坐标系统（CGCS2000）中走向是基础方位参数，所有测量和GIS数据依赖统一坐标系
倾向Dip Direction
垂直于走向、沿煤层倾斜面向下的方向
运维含义
倾向决定工作面推进方向，上山/下山开采的通风、排水、运输方案截然不同
IT关联点
智能开采系统根据倾向角度自动调整支架姿态和采煤机截割参数
标高Elevation
某点相对于海平面的垂直高度（m）
运维含义
标高决定矿井水平划分（如-50m水平、-200m水平），影响提升运输距离和排水扬程
IT关联点
三维地质模型中所有巷道和煤层数据均含标高信息，是空间分析的基础
采区Mining District / Panel Area
阶段内沿走向划分为若干独立开采单元
运维含义
采区是生产组织的基本单元，每个采区有独立的通风、运输、排水系统，运维管理的最小完整单元
IT关联点
采区级数据采集与监控系统（SCADA）独立运行，数据汇总至矿井集控中心
带区Strip Area
沿煤层走向划分的长条形开采区域
运维含义
带区开采适用于倾斜长壁工作面，每个带区对应一个工作面，简化运输和通风系统
IT关联点
带区编号是生产调度系统和MES中的关键组织维度
阶段Level / Stage
沿煤层倾斜方向按标高划分的开采层次
运维含义
阶段划分决定矿井开采深度和水平大巷布置，直接影响提升、通风、排水等系统设计
IT关联点
矿井三维模型以阶段为分层基准，各阶段传感器数据按层级组织
煤层层间距Inter-seam Spacing
相邻煤层之间的岩层距离
运维含义
层间距决定是否可以近距离煤层群开采，影响保护层开采方案和重复采动影响
IT关联点
多煤层开采时需建立层间应力传递模型，数据纳入智能开采决策系统
基岩厚度Bedrock Thickness
煤层上方基岩层的厚度
运维含义
基岩厚度影响地表移动变形量和导水裂缝带是否沟通地表，是安全开采的关键参数
IT关联点
数值模拟所需的基础地质参数，纳入矿井数字孪生底座
覆盖层厚度Overburden Thickness
煤层上方所有岩层（含松散层）的总厚度
运维含义
浅埋深矿区（覆盖层<100m）矿压显现剧烈，需特殊支护方案，也是地表沉降评估的基础
IT关联点
浅埋深条件对智能开采系统的矿压监测频率和预警阈值有特殊要求
煤层厚度Coal Seam Thickness
煤层的垂直厚度（m）
运维含义
煤层厚度直接决定采高选择和开采工艺，薄煤层（<1.3m）需薄煤耙矿机或刨煤机，厚煤层（>3.5m）需放顶煤或大采高
IT关联点
采煤机选型和液压支架采高范围的核心依据，智能化系统据此匹配截割模板
支撑式液压支架Supported Roof Support
依靠立柱支撑力直接维护顶板的支架类型
运维含义
适用于顶板稳定的薄-中厚煤层，结构简单但防矸能力差，运维重点在立柱密封性和初撑力保持
IT关联点
支架压力传感器采集初撑力和工作阻力数据，上传至矿压监测系统
掩护式液压支架Shield Roof Support
带有掩护梁隔绝采空区矸石的支架类型
运维含义
适用于顶板破碎、来压强烈的条件，防矸性能好但支护效率较低，运维重点在掩护梁连接件和推移装置
IT关联点

运维含义
如钢丝绳探伤、齿轮箱油液分析、电气绝缘测试等
IT关联点
专项检查报告数字化存档，关键参数纳入设备健康档案
预防性维护Preventive Maintenance (PM)
按固定周期执行的维护计划
运维含义
基于时间或运行量的定期更换、润滑、调整，减少突发故障
IT关联点
PM计划录入EAM/CMMS系统，自动生成工单并跟踪执行
预测性维护Predictive Maintenance (PdM)
基于设备状态监测数据预测故障并安排维护
运维含义
通过振动、温度、油液等在线监测数据，利用算法预测设备剩余寿命，精准安排维修
IT关联点
PdM是智慧矿山设备管理的核心方向，传感器数据→AI模型→维护决策→工单执行全链路数字化
MTBFMean Time Between Failures
平均故障间隔时间（h）
运维含义
衡量设备可靠性的核心指标，MTBF越长说明设备越可靠，运维目标是持续提升MTBF
IT关联点
MTBF数据从设备故障台账自动计算，是设备选型和大修决策的重要依据
MTTRMean Time To Repair
平均修复时间（h）
运维含义
衡量维修效率的指标，MTTR越短说明故障恢复越快，运维需优化备件和维修流程
IT关联点
MTTR从工单系统自动统计，是运维KPI考核的关键指标
OEEOverall Equipment Effectiveness
设备综合效率（%）
运维含义
OEE = 可用率 × 性能率 × 合格率，综合衡量设备利用效率，综采面OEE一般要求≥80%
IT关联点
OEE数据采集需整合生产、设备、质量三个维度的数据，是MES/EAM的核心KPI
TPMTotal Productive Maintenance
全面生产维护
运维含义
全员参与的设备管理理念，强调"自主保全+专业保全"相结合，目标是零故障、零缺陷
IT关联点
TPM管理平台支持自主保全检查、OEE统计、改善提案等功能
RCMReliability-Centered Maintenance
以可靠性为中心的维修
运维含义
根据设备功能重要性、故障模式和后果，制定差异化维护策略
IT关联点
RCM分析结果录入EAM系统，指导PM/PdM策略制定
备件ABC分类法ABC Classification
按备件重要性和价值分为A/B/C三类的管理方法
运维含义
A类（关键备件，如采煤机截割电机）必须保持库存；B类适度储备；C类按需采购
IT关联点
ABC分类数据与EAM系统集成，驱动库存策略和安全库存计算
安全库存Safety Stock
为防止缺料而设定的最低库存量
运维含义
关键备件（如提升机制动器摩擦片）的安全库存直接影响停机风险，运维需定期评估和调整
IT关联点
EAM系统根据消耗速率、采购周期和安全库存自动触发采购申请
设备报废标准Equipment Decommissioning Criteria
设备达到技术或经济寿命后强制退出使用的规定
运维含义
煤矿设备有明确的报废年限和技术指标（如提升机主轴探伤不合格即报废），运维需建立报废台账
IT关联点
设备报废流程在EAM系统中完成审批，触发采购替换流程
设备周转率Equipment Turnover Rate
设备在不同工作面之间调转使用的频率
运维含义
综采设备搬家倒面是大型矿井的常态，周转率高说明产能紧张但也增加设备损耗
IT关联点
设备周转计划纳入生产调度系统，搬家倒面方案需提前3个月规划
大修周期Overhaul Cycle
设备两次大修之间的运行时间
运维含义
采煤机大修周期一般为过煤量200-500万吨，液压支架大修周期5-8年，运维需精确跟踪
IT关联点
大修计划由EAM系统根据累计运行量自动触发，与生产计划协调
项修Item Overhaul / Component Repair
针对设备特定项目（部件）的修理
运维含义
不如大修全面，仅修理或更换达到极限状态的部件，如采煤机截割部项修
IT关联点
项修工单纳入EAM管理，记录修理内容和更换配件
临修Emergency Repair
设备突发故障后的紧急抢修
运维含义
临修是运维最想减少的维修类型，每次临修都要做故障分析报告（RCFA）
IT关联点
临修工单从告警/报修自动生成，要求最快响应，事后必须录入故障原因和整改措施

流程1：1. 综采工作面IT设备安装与部署流程 ▸
流程目的：规范新工作面IT基础设施从方案设计到上线运行的全过程，确保设备选型合理、安装规范、系统联调达标，实现工作面"网络全覆盖、视频无盲区、定位精准化、传感可靠化"的智能化运行基础。
关键控制点：
  1. 入井前地面联调：未做地面联调直接入井安装，会导致井下发现问题后设备升井维修，运输周期长（单次4-8小时），严重影响工期
  2. 防爆安全检查：防爆设备失检入井，可能导致安全事故，属于红线问题
  3. 光缆弯曲半径：弯曲半径不足会导致光纤断裂或损耗增大，后期排查困难
  4. VLAN/IP规划一致性：地面规划与井下实际配置不一致会导致网络不通或环网环路
  5. 传感器标定：未标定直接投用会导致数据不准，影响安全判断

需求分析与现场勘查 ↓ 方案设计 → [评审通过?] ├─ 否 → 修改方案 → 重新评审 └─ 是 → 设备选型与到货验收 ↓ [MA/防爆检查合格?] ├─ 否 → 退换设备 └─ 是 → 入井前地面联调 ↓ [联调全部通过?] ├─ 否 → 地面整改/更换设备 → 重新联调 └─ 是 → 入井安全检测与运输 ↓ 安装布线（光缆/网线/设备/供电） ↓ 系统调试（网络/视频/定位/传感/通信） ↓ [调试全部达标?] ├─ 否 → 问题整改 → 重新调试 └─ 是 → 72小时联合试运转 ↓ [试运转合格?] ├─ 否 → 整改 → 重新试运转（72h重计） └─ 是 → 验收移交 → 进入日常运维
流程2：2. 综采工作面回撤与迁移流程 ▸
流程目的：规范工作面回采结束后IT设备的有序回撤、分类处理和资产台账更新，确保可复用设备完好率最大化、资产数据实时准确、回撤过程安全高效。
关键控制点：
  1. 回撤顺序：过早拆除核心交换设备会导致其他设备失去网络监控，必须按"先末端后核心"顺序
  2. 设备清点差异：升井后清点数量与台账不符，必须查明原因（遗漏井下/运输途中丢失），不允许直接平账
  3. 防爆设备保护：回撤过程中隔爆面磕碰损伤，会导致设备防爆性能降低，再次入井存在安全隐患
  4. 台账同步更新：台账未及时更新会导致新工作面部署时使用已损坏设备，造成二次返工

接到矿方回撤通知 ↓ 回撤计划制定（设备清单/顺序/运输/分类预案） ↓ 设备断电与线缆回收（先末端后核心） ↓ 设备升井运输 ↓ 逐台清点与外观检查 → [数量/台账一致?] ├─ 否 → 追查差异原因 → 补充清点 └─ 是 → 设备分类功能检测 ↓ ┌─ A类(可复用) → 入库"可用设备库" → 台账更新"库存-可复用" ├─ B类(需维修) → 转入维修 → 维修后入库 → 台账更新"维修中"→"库存" ├─ C类(需保养) → 保养后入库 → 台账更新"保养中"→"库存" └─ D类(已报废) → 报废审批 → 台账更新"已报废"
流程3：3. 掘进面设备迁移流程 ▸
流程目的：规范掘进面IT设备随工作面推进的周期性迁移作业，确保迁移期间业务中断时间最短化（≤30分钟/次），设备安全零损坏，迁移后系统功能100%恢复。
关键控制点：
  1. "先建后拆"策略：不采用先拆后建会导致业务中断时间延长至2-4小时，严重影响掘进作业和安全监控
  2. IP地址冲突：新设备安装时若提前接入网络，新旧设备IP冲突会导致网络异常
  3. 定位基站坐标更新：坐标不及时更新会导致定位系统显示人员位置偏移，影响安全管控
  4. 传感器前移时机：传感器必须随掘进迎头及时前移，否则监控区域出现盲区，违反《煤矿安全规程》
流程图
获取掘进进尺计划 → 确认迁移需求 ↓ 迁移前准备（工具/材料/新位置条件确认） ↓ 新位置设备安装布线（先建，暂不接入网络） ↓ 确认安全间隙 → 业务切换（≤30min） ↓ [各系统恢复正常?] ├─ 否 → 排查故障 → 恢复 → 重新确认 └─ 是 → 旧位置设备拆除回收 ↓ 台账与系统更新（位置/拓扑/坐标/巡检点）
流程4：4. 日常巡检标准化流程 ▸
流程目的：建立分级（日/周/月）标准化巡检体系，实现设备隐患早发现、早处置，保障智能化系统可用率≥99.5%，将故障消灭在萌芽状态。
关键控制点：
  1. 巡检漏项：关键设备未被巡检到导致隐患未发现，需要通过巡检路线标准化和APP强制逐项确认来控制
  2. 异常处置闭环：上报后未及时处置导致故障扩大，需要工单系统跟踪闭环
  3. 纸质巡检造假：纸质记录可能造假，需要电子巡检（GPS定位+时间戳+拍照）+ 不定期抽查
  4. 安全专项检查走过场：防爆检查不认真导致安全隐患，需要专项检查表逐项打钩+拍照留痕

流程5：5. 故障三级响应处置流程 ▸
流程目的：建立"一级（驻矿现场）→二级（远程专家）→三级（厂商/集成商）"分级响应体系，确保故障在最短时间内得到最有效处置，核心系统可用率≥99.9%。
关键控制点：
  1. P1故障响应时效：核心系统中断超过30分钟可能影响安全生产，必须保证5分钟响应、30分钟恢复（或启用备用）
  2. 升级时机判断：一级死磕不升级导致错过最佳处置窗口，必须严格执行时限升级机制
  3. 工单记录完整性：记录不完整导致同类故障重复排查，浪费资源
  4. 重复故障根因分析：同一设备/同一类型故障反复发生必须找到根因，不允许反复"重启恢复"了事

流程6：6. 光缆故障处理流程 ▸
流程目的：规范井下光缆故障的定位、抢修、熔接和恢复全过程，确保光缆故障处置时效达标（主干光缆≤2小时恢复），熔接质量满足传输要求。
关键控制点：
  1. OTDR测试准确性：距离换算不准确会导致在错误位置开挖，浪费时间
  2. 熔接损耗控制：单芯损耗>0.2dB会导致该通道误码率升高，影响视频质量或数据传输
  3. 井下瓦斯监测：熔接机放电产生电弧，在瓦斯浓度超标环境下可能引发爆炸
  4. 接头盒密封：密封不良导致进水，会加速光纤劣化，3-6个月后再次出现高损耗
  5. 弯曲半径：储纤盘中弯曲半径不足会导致宏弯损耗，影响传输质量
流程图
光路告警 → 初步判断（故障光路/范围/类型） ↓ OTDR测试定位 → 双向测试取平均 → 距离换算 → 确定巷道位置 ↓ 抢修准备（工具/材料/安全确认）→ 入井到达故障点 ↓ 现场确认故障 → 光缆开剥 → 裸光纤制备 ↓ 逐芯熔接 → [每芯损耗≤0.1dB?] ├─ 否 → 重新熔接 └─ 是 → 热缩保护 → 盘纤入接头盒 ↓ OTDR复测 + 光功率测试 → [指标合格?] ├─ 否 → 排查问题 → 重新熔接 └─ 是 → 网管确认业务恢复 → 接头盒封装 → 标识更新 ↓ 记录归档 → 光缆管理系统更新
流程7：7. 设备全生命周期管理流程 ▸
流程目的：建立设备从采购到报废的全生命周期管理体系，通过设备电子身份证（一机一档）实现每台设备的完整履历追踪，结合健康度评估模型实现预测性维护，最大化设备利用率和使用寿命。
关键控制点：
  1. 电子身份证信息实时更新：信息滞后会导致决策失误（如使用已超期未检的防爆设备）
  2. 健康度评估客观性：不能凭主观判断，必须基于数据模型
  3. 预防性维护执行率：C级设备的预防性维修计划执行不到位会导致D级故障频发
  4. MA/防爆证书有效期管理：证书过期设备严禁继续使用，系统需设置到期预警
  5. 报废设备数据清除：涉及敏感配置数据的设备报废前需清除数据
流程图
采购需求 → 到货验收 → [合格?] ├─ 否 → 退换货 └─ 是 → 录入电子身份证 → 入库 ↓ 领用申请 → 审批 → 出库 → 安装 → 状态"运行中" ↓ ┌─── 运行期管理（循环）───┐ │ 点检 → 保养 → 维修 │ │ 性能监测 → 数据采集 │ └─────────┬───────────────┘ ↓ 设备健康度评估（A/B/C/D） ↓ ┌─ A/B → 继续正常运行 ├─ C → 制定维修/更换计划 → 执行 └─ D → 立即维修/更换 ↓ [达到报废条件?] ├─ 否 → 继续运行管理 └─ 是 → 报废鉴定 → 审批 → 处置 → 状态"已报废"
流程8：8. 备件管理流程 ▸
流程目的：建立科学的备件管理体系，确保关键备件在需要时可及时供应，同时控制库存成本，实现"井下急需30分钟到位、地面备件当日到位"的保障目标。
关键控制点：
  1. 安全库存执行：关键备件低于安全库存不及时补货，一旦故障无备件更换导致系统长时间瘫痪
  2. 紧急领用后补手续：紧急领用不补手续会导致库存数据不准确，影响后续补货决策
  3. 备件质量把控：使用不合格备件会导致二次故障，必须验收检验
  4. 账实一致性：账实不符会导致以为有库存实际没有的情况，必须定期盘点
  5. 井下备件库环境：井下潮湿环境可能导致备件存储期间受潮损坏
流程图

流程9：9. 网络安全运维流程 ▸

流程10：10. 数据备份与灾备流程 ▸
流程目的：建立覆盖所有关键业务系统的数据备份与灾备体系，确保数据在硬件故障、人为误操作、勒索攻击等场景下可快速恢复，RPO（恢复点目标）和RTO（恢复时间目标）满足煤矿安全生产要求。
关键控制点：
  1. 安全监测数据零丢失：瓦斯、CO等安全监测数据一旦丢失会影响安全追溯，必须保证实时同步+本地缓存双保险
  2. 备份数据有效性：备份成功≠可以恢复，必须通过定期恢复演练验证备份有效性
  3. RPO/RTO达标：实际RPO/RTO超过目标值意味着灾难发生时数据丢失量或恢复时间不可接受
  4. 备份数据安全性：备份数据被篡改或删除（如勒索病毒同时加密在线数据和备份数据），必须有离线/不可变备份
  5. 存储空间管理：存储空间耗尽会导致后续备份全部失败，必须有容量预警和自动扩容机制

价值量化公式（5个）
公式1 · 通讯中断损失
年损失 = 单次中断时长(h) × 中断频次(次/年) × 单面时产(t/h) × 煤价(元/t)
示例：2h × 12次 × 4375t/h × 600元/t ≈ 6264万元/年（仅单面）
公式2 · 故障诊断提效收益
年节省 = (当前诊断时间 - 目标时间) × 故障次数/年 × 单位时间停产成本
示例：(35min - 15min) × 145次 × 3万元/min停机成本 ≈ 可量化收益
公式3 · 资产台账人力节省
年节省人力 = 当前台账维护人时/月 × 12 × 人力成本 × 自动化率
示例：台账自动发现替代60%人工 → 4个智维中心×2人×4h/天×250天 = 5000人时/年可释放
公式4 · 一网多业务承载降本
年节省 = (原网络套数 - 1) × 单套设备折旧 + 光纤维护工作量减少 × 人力成本
示例：井下原来4张网→1张物理切片网，设备/光纤/维护各降60%+
公式5 · 知识沉淀ROI
ROI = (新人上手周期缩短月数 × 培训成本/人 × 新人批次) + 专家时间释放价值
示例：新人上手从6个月→3个月 × 年招10人 × 培训期间工资 ≈ 直接节省
